# JlAgent 打包说明

使用 **UnifyPy**（打 exe）+ **Inno Setup 6**（打安装包）打包 JlAgent。

## 交付物

| 文件 | 说明 |
| --- | --- |
| `build_package.bat` | 一键打包脚本（**以后直接双击运行它即可**） |
| `build.json` | UnifyPy 打包配置（入口、数据文件、Inno Setup 选项） |
| `dist\JlAgent.exe` | 打包出的单文件可执行程序 |
| `installer\JlAgent-1.0.0-x86_64.exe` | Inno Setup 生成的安装程序 |

## 如何使用

1. 双击 `build_package.bat`（或命令行运行它）。
2. 脚本会自动：检查/安装依赖（textual、openai、trafilatura、pyinstaller）→ 检查 Inno Setup → 调用 UnifyPy 打包 → 生成 exe 与安装包。
3. 产物输出到 `dist\` 和 `installer\`。

> 依赖安装只需要第一次执行；以后源码没新增依赖时脚本会直接跳过安装步骤。

## 需要时可修改的配置

打开 `build_package.bat` 顶部的"可配置项"，可改：

- `UNIFYPY`：unifypy 程序路径（默认 `D:\Python313\Scripts\unifypy.exe`）
- `PYTHON`：Python 命令
- `ISCC`：Inno Setup 的 ISCC.exe 路径（默认 `D:\无用软件\Inno Setup 6\ISCC.exe`）
- `APP_VERSION`：应用版本号
- `CONFIG_FILE`：UnifyPy 配置文件（默认 `build.json`）

打开 `build.json`，可改应用名、入口、onefile/onedir 模式、数据文件、隐藏导入等。

## 打包要点（已处理好）

- **入口**：`run.py`（TUI 界面）。
- **数据文件**：`config.ini`（放到打包根目录，匹配 `core/config.py` 的 `BASE_DIR`）和 `tui/app.tcss`（放到 `tui/`，匹配 textual 的 `CSS_PATH`）都已通过 `pyinstaller.add_data` 打进包。
- **动态导入**：`run.py` 用 `importlib.import_module("tui")` 动态加载界面模块，PyInstaller 静态分析抓不到，已通过 `hidden_import` 显式包含 `tui`、`core` 等包，否则会报 `module 'tui' has no attribute 'run_tui'`。
- **spec 缓存**：unifypy 会缓存生成的 `JlAgent.spec`，改 `build.json` 后它可能不重新生成。脚本已加入"删除旧 spec"步骤，确保每次都用最新配置构建。
- **脚本编码**：`build_package.bat` 为 GBK + CRLF，并在开头 `chcp 936`，保证含中文路径也能被 cmd 正确解析。

## 注意

- **配置是打包进 exe 的**：`config.ini` 在构建时写入 exe 内部，安装后无法直接改模型/工作目录/API Key，需要改源码配置后重新打包。
- **API Key 会随包分发**：`config.ini` 里的百度 API Key 会被打进 exe/安装包，请勿把安装包公开分发。
- 应用默认连接本地 LM Studio（`http://127.0.0.1:1234`），运行时需先启动它。
